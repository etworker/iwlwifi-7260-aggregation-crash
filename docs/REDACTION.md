# 脱敏规范（入库前必读）

本仓库所有 SSID / MAC / IPv6 / IPv4 均为**一致性占位符**，与真实值一一对应但不同。映射表不公开。

规则：
1. 任何新日志/证据入库前，必须先做与既有占位符一致的字段替换，保持证据链对应关系；
2. 真实值永远不要提交进本仓库（包括 issue、commit message）；
3. 已知占位符：SSID `HomeNet_5G`/`HomeNet`/`OfficeNet`；路由 MAC `a4:a9:30:e2:76:da`/`:d9`（前缀 `a4:a9:30:e2:76:`）；办公 AP `00:be:75:73:7b:e3`；IPv6 前缀 `2408:8207:2500:c6fa::/64`；IPv4 网段 `192.168.100.0/24`。
